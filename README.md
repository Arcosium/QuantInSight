# QuantInSight

전략 연구와 계좌 현황: https://quantinsight.ai-ve.uk

금일 시황 / 데이터셋 / 한국주식 / 미국주식 / 크립토 / 타임폴리오로 구분한다. 금일 시황이 시작 화면이다.
한국주식은 페이퍼매매·한투 실매매·연구소, 미국주식과 크립토는 페이퍼매매·연구소,
타임폴리오는 모의매매·연구소로 구성한다. 한투 모의매매는 제거했다.
한투 실매매는 사용자 요청으로 정지 상태다. 화면·전략 적용 API·기존 주문 함수에서 주문을 차단한다.
타임폴리오는 13회 대회 계정을 직접 조회하며 이전 대회 장부와 합치지 않는다.
크립토 모의매매는 QuantInSight 화면에서 논문 기반 고정 모델 장부를 직접 표시한다.
모델 선택·마감 수익률 곡선·보유 포지션·진입과 청산 기록·항상 펼쳐진 운영 로그를 제공한다.
CNN 곡선은 원본 장부의 수수료 반영 마감 기록을 읽으며 펀딩비 제외 기준을 표시한다.

## 금일 시황과 실험 지도

시황에는 코스피·S&P 500·BTC 최근 3개월 일봉과 직전 관측 종가 대비 변동률을 표시한다.
시세는 Yahoo Finance 공개 자료를 5분 캐시하며 출처·관측 시각·갱신 실패를 명시한다.
기존 뉴스 아카이브의 최근 7일 기사를 시장별로 정리하고 기사 제목·제공 설명·출처·발행 시각을 표시한다.
새 연구 후보는 실제 완료 이벤트 기준 최근 7일, OS 9개월 순수익률 양수·샤프 1 이상·손실월 3 이하로 선별한다.
이는 탐색 필터이며 통계적 유의성 검증을 뜻하지 않는다.

실험 지도에서 실제 적용 장부가 확인된 모델은 다이아몬드다. 크립토 기존 5개 모델도 같은 지도에 표시한다.
논문 CNN 두 모델은 겹치는 날짜를 제거한 검증 fold, GBM 세 모델은 실현 순자산 운용 기록이 기준이다.
관측기간이 다른 참고점은 기간과 비용·운용 기준을 표시하고 OS 순위·파레토·유전 선발에는 넣지 않는다.
오래된 평가 기간의 적용 모델도 본인 운용 장부와 배포 상태가 확인되면 참고점으로 유지한다.

각 연구소의 자동 적용 토글은 기본 꺼짐이다. 켠 시점의 전략은 기준선으로 저장하고 이후 발견되는
동일 평가 달력의 새 파레토 모델 중 수익률 최대, 동률이면 손실월 최소인 후보를 재학습한다.
한국·미국·크립토 자체 페이퍼 계좌가 대상이며, 검증 완료까지 기존 모델을 유지한다.
토글 해제는 대기 작업을 취소하고 진행 중 재학습의 최종 적용도 차단한다. 웹 서비스가 30초마다
대기열을 점검하며 여러 웹 프로세스는 vault의 파일 잠금으로 중복 적용을 막는다.
타임폴리오는 13회 운용 모델 연결·규칙 검증 전이라 자동 적용 토글이 잠겨 있다. 한투 실매매는 계속 정지한다.

## 로그인과 연결

관리자는 로컬에서 최초 생성한다. 회원가입은 일반 사용자만 생성하며 서버 자원 설정은 관리자 전용이다.
회원은 OpenAI, Anthropic, Gemini, DeepSeek, OpenRouter 중 하나와 모델 ID·API Key를 등록해 알파 후보를 만든다.
관리자는 로컬 AI를 사용한다. 모델 응답은 허용된 전략 파라미터로 검증하며 생성된 코드는 실행하지 않는다.
회원가입의 한국투자증권·타임폴리오 연결은 선택 항목이다. 가입 후 계좌 연결 화면에서 추가·변경할 수 있다.
계좌 정보·API Key는 회원별로 암호화해 vault에 두고 비밀번호는 scrypt 해시로 저장한다.
계좌 조회는 해당 회원의 연결만 사용한다. 한투 실매매 정지 중에는 증권사 조회도 실행하지 않는다.
세션은 HttpOnly·SameSite 쿠키, 외부 HTTPS에서는 Secure 속성을 사용한다. 변경 API는 동일 출처를 검사한다.
Cloudflare는 이 도메인에 한해 앱 로그인 화면으로 통과시키며 모든 데이터 API는 앱 인증을 거친다.

## 데이터와 연구 상태

데이터셋에는 실제 보유 시작·종료일을 표시한다. 현재·과거 분봉은 자산별로 묶는다.
날짜는 DB·Parquet·패널 원본에서 읽으며 파일 수정일을 데이터 기간으로 대신하지 않는다.
보관소의 최소·최대일은 합집합 범위이며 모든 종목에 연속 자료가 있다는 의미가 아니다.

신규 평가 기간은 한국 날짜 기준 어제까지의 최근 36개월이며 매일 하루씩 이동한다.
IS 24개월·OS 9개월·ROS 3개월로 구분하고 부모 선택·파레토·자동 적용에는 OS만 사용한다.
실행 중 실험의 기간과 입력은 고정하며 새 실험부터 새 날짜를 사용한다. 미국 장 또는 UTC 일자가
아직 완료되지 않았거나 수집 자료가 부족하면 대기한다. 손실월은 평가 시작일에 맞춘 월 단위로 센다. 주식은 시장 거래일 달력, 크립토는 전체 달력일과 일치해야 한다.
학술제의 동결된 검증 시세는 2026-02-27까지이며 그대로 보존한다. QuantInSight의 별도 확장 입력은
한국 NAVER 일봉 303종목과 미국 동일 제공사 수정 일봉 40종목이다. 평가 구간과 각 구간의 거래일 수는 실행 날짜에 따라 다시 계산한다. 2026년 한국 추가 휴장일 6월 3일·7월 17일을 달력에 반영했다.
현재 수집 대상 종목을 사용하는 개발 결과이므로 생존·수집 선택 편향과 기업행사·체결 근사의 한계가 있다.

`autofolio.labs`는 네 연구소를 지속적으로 운영한다. 로컬 AI가 허용된 모델·필드·학습기간을
제안하고, 완료된 실제 결과에서 부모를 골라 교차·변이한다. 세대별 난수 시드도 기록하며
사용자가 각 연구소의 중단 버튼을 누를 때까지 반복한다. 중단 시 실행 중인 실험은 마무리하고
새 실험은 시작하지 않는다. 워커가 재시작되면 설정과 대기열을 복구한다.

학습 모델은 Ridge·ExtraTrees·HistGradientBoosting·MLP·Residual MLP·LSTM·GRU·TCN·Transformer다.
신경망은 compact/large 크기를 번갈아 탐색하며 현재 large 설정은 약 1,200만~1,500만 파라미터다.
학습기간·시퀀스 길이·에폭·학습률·목표·OHLCV 필드·재학습주기·매수/매도규칙·비중·노출·손절/익절을
함께 교차·변이한다. 뉴스는 실제 수집 기간이 학습 구간을 덮을 때만 활동량 입력으로 사용하며
현재의 짧은 수집 이력을 3년치 뉴스로 간주하지 않는다. 공시·이미지·텍스트 멀티모달은 아직 학습 입력에 포함하지 않는다.
각 재학습 기준일 전에 확정된 라벨만 학습하고 다음 거래일 시가 체결을 모의한다.
신경망 내부 검증도 시간순으로 분리하고 라벨 경계를 제거한다. ROS 구간 중에는 재학습하지 않는다. 실험마다 실제로 학습하며,
학습 없는 기존 가격 비교 결과는 새 연구소의 기본 리더보드에서 제외한다.

타임폴리오는 별도 보유기간·비용·보수적 업종/소형주/노출 제한과 주간 회전율 점검을 사용한다.
과거 시점의 종목 지정·업종·시총 규칙 검증은 미완료이므로 대회 적합성을 인증하지 않고 새 전략 적용을 막는다.
기존 13회 계좌 운용과 장부 조회는 유지한다. 크립토 연구는 원본 분봉에서 전체 보유 유니버스의 공유 일봉을
만든 뒤 36개월을 확인한다. 잘못된 봉은 기록 후 제외하며 결측값을 보간하지 않는다.
전체 날짜가 부족하면 동일 거래소·종목의 확정 일봉을 인접 완전일의 OHLCV와 대조해 연구 입력에 보완하고,
요청 URL·응답·검증 내역을 보존한다. 수집 원본 분봉은 수정하지 않는다.

실험 모델 가중치는 디스크에 저장하지 않는다. 결과·거래 원장·순차 학습 증거·재현 명세를 보관하고,
입력 스냅샷과 버전별 학습·신경망·체결 코드는 여러 전략이 공유한다.
학습 파라미터 수·표본 수·소요 시간·에폭별 손실을 기록하고 실시간 진행 정보를 제공한다. 명세에는 원본 해시, 입력 필드, 시드,
학습/평가 경계, 패키지 버전, 코드 해시를 저장한다. 적용 요청 시 보존한 학습 코드와 동일 데이터로
명세의 마지막 학습 기준일 모델을 재학습한다. 분기별 평가 모델 하나를 그대로 복원했다는 뜻은 아니다.
데이터·가중치 변조나 라이브러리 버전 차이는 허용하지 않는다.

적용한 모델만 가중치를 유지하고 후속 모델 적용 시 이전 가중치를 정리한다. 한국·미국·크립토의
자체 페이퍼 계좌는 외부 주문 API 없이 확정 일봉을 관찰하고 다음 시가 체결을 모의한다.
적용 이전의 과거 거래를 실제 운용 기록처럼 재생하지 않는다. 새 크립토 전략을 선택하기 전에는
기존 논문 모델 장부를 표시하고, 선택 후에는 해당 회원의 자체 페이퍼 계좌를 표시한다.

CPU·메모리·동시 실행 한도는 공유 워커 cgroup과 스케줄러가 적용한다. 데이터 준비·AI 후보 요청·모델 학습·
재학습·페이퍼 갱신도 동시 작업 수에 포함한다. 외부 로컬 AI 서버의 자체 메모리/GPU 한도는 별도다.
저장공간 부족 등 자원 제한은 새 작업을 대기시키며 운영 원본과 수집기는 이동하거나 중지하지 않는다.
신경망은 CPU에서 한 번에 하나씩 실행하며 워커 메모리 한도가 6GiB 미만이면 대기한다.
관리 설정은 `neural_research_enabled`, `labs_v2_enabled`, `lab_enabled_<market>`, `research_campaign_owner`다.

## 실행과 검사

```sh
python3 -m pip install -r requirements.txt
python3 -m uvicorn autofolio.app:app --host 127.0.0.1 --port 8997
python3 -m autofolio.worker
python3 -m pytest tests -q
```

운영 호스트의 시장 달력 의존성은 vault/QuantInSight/python-deps에 격리 설치했다. 공유 Python 패키지는 덮어쓰지 않는다.
`quantinsight.service`의 기존 `server.app:app`도 같은 앱이다. CPU·메모리 한도는 autofolio-worker cgroup에 실제 적용한다.
연구 결과와 기존 계좌 데이터는 vault 링크를 유지한다. 연구 모델·DB·수집 원본을 반복 복사하지 않는다.
배경 이미지·폰트는 바이너리 공개 검사 정책에 따라 GitHub 소스 사본에서 제외한다.
